# 验证说明

## 自动化验证

在项目根目录运行 `make test`，按顺序执行 Go 集成测试、Python JWT 合约测试、前端分类逻辑测试与 TypeScript/Vite 生产构建。也可单独运行：

```bash
cd backend
go test ./...
go vet ./...
```

Go 集成测试使用临时目录和独立 SQLite 数据库，不读取或修改开发数据。身份认证请求由内存模拟传输层处理，不访问真实第三方服务；测试中的账号、身份与文件内容均为临时合成输入。

主要覆盖：

- 首次启动仅创建默认管理员和必要设置，业务内容表为空；再次启动不重置账号与设置。
- 未配置实名认证 API 时默认关闭，无网络请求；公开接口不返回认证地址。
- 配置 URL、字段路径和成功值验证，支持关闭认证、模板参数编码、嵌套/数组字段、错误响应拒绝绑定。
- 用户/管理员权限、密码变更后的会话撤销、验证码、身份唯一性及 QQ 绑定码过期/重复消费。
- 多级分类创建、缩进顺序、子树移动、循环引用拒绝与作业标题分组。
- 分片上传、断点续传、完整哈希校验、跨用户物理去重、下载权限及引用清理。
- 提交规则、撤回、提交历史和 WebP 头像转换。

## 浏览器验证

已验证过登录、后台表单、作业发布、上传、提交历史、主题切换、分类标题层级和右侧粘性筛选布局。调试截图与可识别的手工测试内容已清理，不作为仓库发布内容。

后续如需手工验证，应使用临时数据目录或隔离的测试数据库，完成后关闭服务并清理测试目录。

## 范围

- SQLite 已运行集成测试；MySQL 和 PostgreSQL 的连接、建库与迁移代码已编译，尚未完成实库集成测试。

## 工程重构验证

- Go 入口调整为 `cmd/server`，业务、模型、配置、数据库和 HTTP 分包后，原有接口集成测试通过。
- 新增多应用实例隔离测试，验证数据库、会话密钥和服务实例互不影响；资源可幂等关闭。
- `go test -race ./...`、`go vet ./...`、Python JWT 测试、前端分类测试与 TypeScript/Vite 构建通过。
- `make format` 已应用全仓库风格，`make format-check` 验证 Go、前端、Python、TOML 与配置文件均符合规范。
- 独立构建 `cmd/server` 二进制，使用临时 SQLite/数据目录验证健康检查、管理员登录、空分类/作业/附件列表、默认关闭认证、SPA 页面及 JS 静态资源；结束后通过 SIGTERM 正常退出。
- 独立启动检查前后对开发数据库计算摘要，确认未修改既有数据；未保留测试进程或手工演示数据。
